Έλληνας DJ σε όλη την Ευρώπη

Με σχολείο τρεις σεζόν στη νυχτερινή ζωή της Μυκόνου, έδρα τις Βρυξέλλες και συχνά ταξίδια: η εκδήλωσή σας δεν χρειάζεται να είναι στο Βέλγιο για να ακούγεται σωστά.

Ένας DJ, έξι χώρες

Κάποιες εκδηλώσεις χρειάζονται έναν DJ που καταλαβαίνει ένα συγκεκριμένο κοινό — έναν ελληνικό γάμο στη Γερμανία, μια χοροεσπερίδα της ομογένειας στη Βιέννη, ένα εταιρικό καλοκαιρινό πάρτι στο Άμστερνταμ, μια γιορτή στην ίδια τη Μύκονο. Ταξιδεύω ήδη ακριβώς για αυτά: για την Ελληνική Φοιτητική Κοινότητα Βιέννης, τις ελληνικές κοινότητες Λουβαίν και Λιλ, και κάθε καλοκαίρι για guest sets στη Μύκονο, όπου πέρασα τρεις ολόκληρες σεζόν στη νυχτερινή ζωή του νησιού.

  • Απλά logistics — τα έξοδα μετακίνησης και διαμονής προστίθενται στην προσφορά με πλήρη διαφάνεια· όλα τα υπόλοιπα λειτουργούν ακριβώς όπως σε μια κράτηση στις Βρυξέλλες.
  • Compact ή πλήρες στήσιμο — μπορώ να ταξιδέψω ελαφρά και να χρησιμοποιήσω τοπικό εξοπλισμό, ή να οργανώσω πλήρη παραγωγή για εκδηλώσεις κοντά στο Βέλγιο.
  • Εμπειρία Μυκόνου — για destination γάμους και πάρτι στην Ελλάδα, έχετε έναν DJ που έχει πραγματικά δουλέψει σε αυτούς τους χώρους και ξέρει τον ρυθμό του νησιού.

Συχνές ερωτήσεις

Ποιες χώρες καλύπτετε;

Το Βέλγιο είναι η βάση μου· παίζω τακτικά σε Ολλανδία, Γαλλία, Γερμανία, Ηνωμένο Βασίλειο, Αυστρία και Ελλάδα. Άλλοι προορισμοί είναι εφικτοί — ρωτήστε με.

Πώς λειτουργεί η τιμολόγηση για εκδηλώσεις εκτός Βελγίου;

Ίδια αμοιβή εμφάνισης με μια κράτηση στο Βέλγιο, συν διαφανή έξοδα μετακίνησης και διαμονής, που αναγράφονται ξεχωριστά στην προσφορά. Για την Ελλάδα το καλοκαίρι, συχνά βρίσκομαι ήδη εκεί — ρωτήστε με για τις ημερομηνίες της σεζόν μου στη Μύκονο.

Μπορείτε να αναλάβετε destination γάμο στη Μύκονο ή στα ελληνικά νησιά;

Ναι — εκεί έμαθα την τέχνη. Γνωρίζω τους χώρους, τον ρυθμό μιας ημέρας γάμου στο νησί, και πώς να συνδυάσω το ελληνικό ρεπερτόριο με ένα διεθνές κοινό.
