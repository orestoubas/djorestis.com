# Google Ads — first campaign for DJ Orestis

Everything below is ready to paste into Google Ads. All headlines are ≤30 characters,
descriptions ≤90, display paths ≤15 — Google's hard limits, already validated.

## Read this before you spend anything

Paid clicks land on a site that currently has **no photos of you and no Google reviews**.
That is the weakest moment to buy traffic: the same €300 will convert roughly twice as
well once real event photos and ~10 reviews are in place. Recommendation: run the small
test budget below now to learn which keywords convert, then scale after photos + reviews.

Second point of honesty: **corporate work is your stated priority, but it is the worst fit
for search ads.** Companies book DJs through agencies, planners and word of mouth — very
few people type "corporate event DJ Brussels" into Google. Weddings and Greek nights are
where the search demand actually is. Corporate is included below, but expect it to spend
slowly and deliver few clicks. For corporate, LinkedIn outreach and the press kit will
outperform ads.

## Campaign setup

| Setting | Value |
|---|---|
| Campaign type | **Search** only — untick "Display Network" (it wastes budget) |
| Goal | Leads → Website visits |
| Bidding | Start **Maximise clicks** with a max CPC limit of €2.50. Switch to Maximise conversions after ~30 conversions are tracked |
| Daily budget | **€10/day** to start (≈€300/month) |
| Locations | Brussels + 30 km radius. Add Leuven, Ghent, Antwerp, Liège later if budget allows |
| Location option | **Presence: people in this location** (not "interested in") — avoids paying for clicks from abroad |
| Languages | English, French, Dutch, Greek |
| Ad schedule | All week, but bid −30% between 01:00 and 08:00 |
| Ad rotation | Optimise: prefer best performing |

Expected performance at €10/day, based on 2026 benchmarks for wedding-vendor keywords
(€2–5 CPC in this category, higher in metro areas): roughly **60–120 clicks/month** and,
at a realistic 3–6% enquiry rate, **2–6 enquiries/month**. One booked wedding pays for
several months of this.

## Conversion tracking — set this up before launching

Without it you are flying blind: you will see clicks but never know which keyword produced
an enquiry.

1. Google Ads → **Goals → Conversions → New conversion action → Website**
2. Enter `djorestis.com`, choose **Set up manually**
3. Create a conversion named **Quote request**, category *Submit lead form*, value: leave
   blank or set an indicative €600 (average booking value helps the algorithm optimise)
4. Since Analytics is already linked, the simplest path is: **Import from Google Analytics
   (GA4)** — create the event in GA4 first, then import it here
5. In GA4 → Admin → Events → **Create event**, condition: `event_name = click` and the link
   URL contains `mailto:` — that captures quote-form submissions, which currently open the
   visitor's mail client

**Better option:** switch the contact form to real in-page submission via Formspree (free
tier, 50/month). Then the thank-you state becomes a clean conversion event. Create the
account with info@djorestis.com, send me the form ID, and I'll wire it into the site in
one push — after that, conversion tracking is exact rather than approximate.

## First 30 days — what to actually do

| When | Action |
|---|---|
| Before launch | Negatives added, conversion tracking live, budget €10/day |
| Day 3 | Check **Search terms** report. Add junk queries as negatives |
| Day 7 | Pause any keyword with 20+ clicks and zero enquiries |
| Day 14 | Compare ad groups. Shift budget toward the one producing enquiries |
| Day 30 | Decide: scale what works, cut what doesn't. Expect Greek + weddings to win |

Ignore *impressions* and *click-through rate* as success measures. The only number that
matters is **cost per enquiry**. If one booking is worth €500+ to you, paying €80–150 for
an enquiry that converts one time in three is profitable.

## Cheaper alternatives worth doing alongside

- **Google Business Profile** — free, and for local searches it often out-performs paid ads
- **Wedding directories** (e.g. Belgian wedding marketplaces) — usually a flat annual fee
  and reach couples who are actively shopping
- **Venue and planner relationships** — a single venue recommending you is worth more than
  any budget here. The press kit in `marketing/presskit/` exists for exactly this
