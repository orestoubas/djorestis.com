# Directory submission pack — DJ Orestis

Everything you need to fill in a listing without writing a word. Open this file, find the
field, copy the block, paste, move on. Target: **5 minutes per directory**.

**How to use it**
1. Read the NAP block (§4) once. Those strings never change, on any site, ever.
2. Open the directory. Pick the description length its field allows from §1, in the language
   from §3.
3. Fill the rest from §2 — those answers cover the fields that come up again and again.
4. Log the row in the tracker (§5) before you close the tab. If you don't log it, you will
   submit twice, and duplicate listings are actively harmful.

**Three things to decide before you start** — all three appear on nearly every form and none
of them can be answered from the website:

- **A phone number.** There is currently no phone number anywhere on djorestis.com or in the
  build config. Directories will ask, and *the same number must go on every one of them*.
  Pick it now, write it in §4, and never vary the formatting.
- **Insurance.** Do you carry public liability (RC professionnelle / BA uitbating)? Several
  wedding platforms have an "insured supplier" tick box. Do not tick it on faith.
- **Payment methods and deposit terms.** Bank transfer only? Deposit percentage? Write it
  once, use it everywhere.

Marked **[TO CONFIRM]** throughout = I could not verify it from the repo and did not invent it.

## 1. Descriptions at every common length

Nine directories will ask for a 150-character blurb, four will ask for 1,000, and one will
give you a 50-character "slogan" box. All fifteen blocks below are written, not translated —
each one reads natively in its own language. Character counts are exact, measured on the
text as printed between the quote marks.

Rules these follow: keyword in the first four words, no superlatives, no client names, no
claims that are not in the fact sheet, no links (most directories strip or reject them).

### Categories — five phrasings, pick whichever the directory offers

Directory category lists never match each other. These are the same business described five
ways; take the closest match the dropdown offers and don't add a second one unless the
directory explicitly allows multiples.

| # | Phrasing | Use when the list is… |
|---|---|---|
| 1 | **DJ** | Google-style precise lists. Always the first choice if it exists — specific beats broad. |
| 2 | **Mobile DJ / DJ service** | UK- and NL-influenced lists that distinguish club DJs from hire DJs. |
| 3 | **Wedding DJ / Wedding music & entertainment** | Wedding platforms (WEWED, Mariages.net, Huwelijk.be). |
| 4 | **Music & entertainment / Entertainment — music** | General business directories (Goudengids, Infobel) with no DJ leaf category. |

## 4. NAP consistency block

NAP = Name, Address, Phone. Search engines cross-check these strings across every listing to
decide whether two mentions are the same business. **Variations do not average out — they
split the signal.** "DJ Orestis" and "DJ Orestis Brussels" are two businesses as far as the
matching algorithm is concerned, and each gets half the credit. This is the single most
common way a directory campaign quietly wastes itself.

Copy these exact strings. Do not improve them.

```
NAME
DJ Orestis

  Not: "DJ Orestis Brussels" · "DJ Orestis - Wedding & Corporate DJ" ·
       "Orestis Vasileiadis DJ" · "DJORESTIS" · "Dj Orestis"
  The legal name "Orestis Vasileiadis" goes ONLY in fields explicitly labelled
  legal/registered/invoicing name.

ADDRESS LINE (public)
Brussels, Belgium

  Where a street address is mandatory: enter your real registered address and set
  it to hidden / "customers do not visit us" if the directory allows it. If it does
  not allow hiding and you are not comfortable publishing it, skip that directory.
  Never a fake address, never a virtual office, never a friend's address, never a
  venue you play at. Google suspends for this and reinstatement is slow.

  Country: Belgium / Belgique / België
  Region where asked: Brussels-Capital Region / Région de Bruxelles-Capitale /
                      Brussels Hoofdstedelijk Gewest

PHONE
[TO CONFIRM — one number, one format, everywhere.]

  When you pick it, write it in international format and never vary:
      +32 XXX XX XX XX
  Not 0032, not 04XX/XX.XX.XX, not a different mobile on the wedding sites.
  If you would rather not publish a personal mobile, get a second SIM or a
  forwarding number BEFORE you start submitting — retrofitting a phone number
```

## 6. What never to go in a directory listing

Six mistakes. The first three get listings rejected or suspended; the last three quietly
waste the work.

**1. Keywords in the business name.** `DJ Orestis Brussels Wedding DJ` will rank slightly
better and then get suspended — this drove a suspension wave in 2026, and reinstatement is
slow. The business name field is for the business name. Keywords go in the description,
where they are free and safe.

**2. A fake, virtual or borrowed address.** A coworking address you don't work from, a
virtual office, a friend's flat, a venue you play at. It is the fastest route to a suspended
Google profile, and directories increasingly cross-check against the company register. If a
form demands a street address and won't let you hide it, walk away from that directory.

**3. Client names without written permission.** The website names firms; **a directory
listing must not**. Use "major international firms based in Brussels" / "des entreprises
internationales à Bruxelles" / "internationale bedrijven in Brussel". A corporate client
finding their name used as marketing collateral on a supplier directory is a relationship
you do not get back, and it is worth far less than the sentence it buys.

**4. Duplicate listings.** Two profiles on the same directory — usually created because the
first login was forgotten — split your signal and look like spam. This is exactly what the
tracker's Login and Live URL columns prevent. If you find a duplicate that predates you
(scraped from another source), claim and merge it rather than creating a third.

**5. An inconsistent phone number or URL.** A different mobile on the wedding sites, `www.`
on half of them, `http://` on the old ones. Each variation is a separate business as far as
the matching goes. See §4 — and fix the source of the variation before submitting, not after.

**6. Superlatives, invented claims and stuffed copy.** "Belgium's best wedding DJ", "the
#1 Greek DJ in Europe", "award-winning". Google's business description guidelines reject
promotional and superlative language outright, several directories moderate for it, and
readers discount it. Everything in §1 is verifiable: nine years, four years' residency, two
festival editions, 500 guests, five genres, four languages. That is a stronger listing than
any adjective, and it survives being checked.

**Two more, less obvious:**

- **Don't leave the price field blank on booking platforms.** Blank prices get filtered out
  of search results on Cueup, ShowBird and the wedding portals. €600 excl. VAT is a floor,
  not a promise, and it screens out the enquiries you don't want.
- **Don't paste a URL into a description field.** Most directories strip them, some flag the
  submission, and the ones that keep them usually make it nofollow anyway. The website field
  is the website field.
